## Regions and Availability Zones

Cloud providers have physical data centers. 
Data centers are all over the world, in Regions. 
AWS has more than 30 regions. 
Those are physical location where data centers are built. 
User needs to choose in which region should you rent the server. 

Availability zones - In each region we have a data center. If data center is unreachable, there is a replication configured, so the service is not affected. each region has multiple availability zones.  

Application should be hosted where the users are located, so the users can access it faster. 

Application can be replicated in multiple regions.
